# LogiDesk 🚛

**LogiDesk** is the logistics billing and Tally data entry desktop automation tool for Shrey Logistics.

---

### 📥 Download & Install

Download the latest standalone executable directly:

👉 **[Download LogiDesk.exe (Latest Release)](https://github.com/shrey2250/Logi-desk-exe/releases/latest/download/LogiDesk.exe)**

*(No Python installation required. Just download and run `LogiDesk.exe` on Windows).*

---

### ✨ Features

- **Automated Bill Generation**: Generates Microsoft Word bills formatted with live embedded Excel tables.
- **OLE Excel Integration**: Embedded route tables can be edited directly inside Word with automatic calculation.
- **One-Click Recalculation**: Recalculate Word bill subtotals, grand totals, and Indian currency words in one click.
- **Built-in Auto Updater**: Automatically checks for updates on launch and updates with one click.
- **Tally Mapping Integration**: Converts transport billing entries into structured formats ready for Tally.

---

### 🔄 Auto-Update
LogiDesk includes a built-in auto-updater. When a new release is published, the app will automatically notify you and allow you to update and restart in one click.
